개인정보처리방침

궁금해쓰 업로더 (gunggeum uploader) · 시행일 2026년 11월 17일

1. 이 도구에 대해

궁금해쓰 업로더는 유튜브 채널 궁금해쓰(@gunggeum_ss)의 운영자가 자기 채널에만 사용하는 개인용 도구입니다. 운영자가 직접 만든 짧은 교육용 영상을 운영자 채널에 올리는 데 쓰입니다. 일반 사용자에게 제공되지 않으며, 운영자 본인 외의 사람은 로그인하지 않습니다.

2. 접근하는 정보

운영자가 Google 로그인으로 허용한 범위 안에서 다음에만 접근합니다.

  • 운영자 채널의 기본 정보 (채널 ID, 채널 이름) — 올바른 채널에 올리는지 확인하는 용도
  • 운영자가 직접 만든 영상 파일을 운영자 채널에 업로드하는 기능

시청자나 다른 채널의 정보는 수집하지 않습니다.

3. 이용 목적

운영자가 만든 영상을 운영자 채널에 올리는 데에만 사용합니다. 광고, 판매, 프로파일링에 사용하지 않습니다.

4. 저장과 보관

로그인 인증 정보(토큰)와 업로드 기록(영상 ID, 제목)은 운영자 본인의 컴퓨터에만 파일로 저장되며 외부로 전송하지 않습니다. 운영자가 원하면 언제든 삭제할 수 있습니다.

5. 제3자 제공

접근한 정보를 판매하거나 제3자에게 제공하지 않습니다.

6. 권한 철회

Google 계정 > 보안 > 서드파티 앱 및 서비스에서 이 도구의 접근 권한을 언제든 철회할 수 있습니다.

7. Google API 서비스 약관

이 도구는 YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(제한적 사용 요구사항 포함)를 따릅니다.
