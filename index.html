Ppsong Diary Briefing — 승승부부(@SSbbubbu) 채널 운영자가 직접 쓰는 개인용 도구

무엇인가요?

유튜브 채널 승승부부 (@SSbbubbu)를 운영하는 부부가 자기 채널에만 쓰는 비공개 도구입니다. 일반 사용자에게 제공되는 서비스가 아니며, 다른 사람의 계정에는 접근하지 않습니다.

  • 매일 아침 내 채널 영상의 조회수·시청 지속 시간 같은 성과 수치를 읽어 운영 메모(브리핑)를 만듭니다. (YouTube Data API, YouTube Analytics API — 읽기 전용)
  • 내가 직접 만든 쇼츠 영상을 내 채널에 올립니다. (YouTube Data API — 업로드)

What is this? (English)

Ppsong Diary Briefing is a private, single-user tool used only by the owners of the YouTube channel @SSbbubbu. It reads performance metrics of the owners' own videos (read-only) to write a daily internal report, and uploads short videos the owners created themselves to their own channel. It is not offered to the public and never accesses anyone else's account.
